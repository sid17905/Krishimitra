## 2. COMMON WINNING PATTERNS

### Pattern 1: STRUCTURE CONSISTENCY
All successful PPTs follow the exact SIH template:
```
Slide 1: Title + Problem Statement
Slide 2: Solution + Innovation
Slide 3: Technical Approach (with flowchart)
Slide 4: Feasibility + Challenges
Slide 5: Impact + Benefits
Slide 6: References
```

### Pattern 2: VISUAL > TEXT
| Element | Winning PPTs | Losing PPTs |
|---------|-------------|-------------|
| Architecture | REQ/RES diagrams, flowcharts | Walls of text |
| Tech Stack | Icon + short label | Paragraph descriptions |
| Process | Numbered steps with arrows | Text descriptions of steps |
| Impact | Icons + 3-5 words per item | Full sentences |

### Pattern 3: SPECIFICITY WINS
- **Winner (Codeline):** "buyfreshdtu.xyz" — actual deployed URL
- **Winner (Codeline):** "Denoising → Otsu Thresholding → 8-connected → Feature Extraction" — specific ML pipeline
- **Your PPT:** "ESP32: Soil Moisture, NPK, DHT22" — specific hardware
- **Losers:** Generic statements like "We use AI to help farmers"

### Pattern 4: HONEST RISK ASSESSMENT
Every notable PPT includes:
- Acknowledged limitations (not just strengths)
- Concrete mitigation strategies
- Honest "show stoppers" or "challenges"
This signals maturity and realistic planning to judges.

### Pattern 5: REAL DATA SOURCES
| PPT | Cited Data Sources |
|-----|-------------------|
| Codeline | Soil Health Card, government databases |
| Tech Natives | Google Cloud Speech API, AWS SDK |
| KrishiMitra | IMD, CPCB/NWMP, Agmarknet, ISRO Bhuvan, Sentinel |

### Pattern 6: MULTI-COMPONENT ARCHITECTURE
Winners show a SYSTEM, not just an app:
- Codeline: Android App + Buyers' Portal + Admin Panel + ML Models
- KrishiMitra: Voice App + ESP32 Hardware + Govt APIs + ML Engine + Alert System

## 5. SIH 2026 TEMPLATE RULES (From Official Format PDF)

**MANDATORY RULES:**
1. Maximum 6 slides (including title slide)
2. Avoid paragraphs — use points/diagrams/infographics/pictures
3. Keep explanation precise and easy to understand
4. Idea should be unique and novel
5. Use ONLY the provided template — don't change idea detail pointers
6. Save as PDF for upload (no PPT, Word, or other formats)
7. Delete "Important Pointers" slide before uploading

**Slide Structure (from template):**
```
Slide 1: TITLE PAGE (PS ID, Problem Title, Theme, PS Category, Team ID, Team Name)
Slide 2: IDEA TITLE (Proposed Solution, How it addresses problem, Innovation & Uniqueness)
Slide 3: TECHNICAL APPROACH (Technologies, Methodology with flowcharts)
```
